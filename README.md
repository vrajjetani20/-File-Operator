# 📔 Personal Journal Manager

## 📌 Overview

A Python console application to manage personal journal entries. It
allows users to: - ➕ Add new journal entries - 📖 View all entries - 🔍
Search entries by keyword or date - 🗑️ Delete all entries - ❌ Exit the
program

## 🛠️ Features

-   Timestamped journal entries
-   File handling with error checking
-   Menu-driven interface
-   Search functionality
